The spoken read drops the hash marks, speaks abbreviations as letters, and does not read the
placeholder as code. Nothing else changes. The placeholder line is the only substitution the
code makes: it becomes the joined guidance lines, or an empty string.

## Guidance is a function of the tool set

Three gates, in this order, and the joined result replaces the placeholder in the base prompt.

```ts
// packages/core/src/session/system-prompt.ts:5
export function make(tools: string[]) {
  return render(PROMPT, tools)
}

export function render(prompt: string, tools: string[]) {
  const instructions: string[] = []
  if (tools.includes("shell")) {
    instructions.push(
      "- Prefer dedicated tools over shell commands; fall back to the shell when a tool cannot do what you need.",
      "- Do not chain shell commands with separators like `echo \"====\";` or `printf '---'`; the output becomes noisy in a way that makes the user's side of the conversation worse.",
    )
  }
  if (tools.includes("write")) {
    instructions.push(
      "- Use the write tool to create files or completely replace their content. Prefer using the edit tool for targeted changes.",
    )
  }
  if (tools.includes("edit")) {
    instructions.push(
      "- Use the edit tool for targeted changes to existing text files. It replaces the exact text in `oldString` with `newString`, and the values must differ. By default, `oldString` must occur exactly once. If it occurs multiple times, include more surrounding context to make it unique or set `replaceAll` to true to replace every occurrence.",
    )
  }
  return prompt.replace("${OPENCODE_TOOL_GUIDANCE}", instructions.join("\n"))
}
```

## The two parts, and how they combine

The first part is the agent's own system text if it has one, otherwise the generated base
prompt; the second is always the instruction baseline. Empty parts are dropped.

```ts
// packages/core/src/session/model-request.ts:100
export const baseTranscript = (input: {
  readonly agent: Agent.Info
  readonly model: SessionRunnerModel.Resolved
  readonly tools: Tool.Snapshot
  readonly initial: string
  readonly messages: ReadonlyArray<SessionMessage.Info>
}) => {
  const providerMetadataKey = input.model.model.route.providerMetadataKey ?? input.model.model.provider
  return {
    providerMetadataKey,
    system: [
      input.agent.system
        ? input.agent.system
        : SessionSystemPrompt.make(input.tools.definitions.map((tool) => tool.name)),
      input.initial,
    ]
      .filter((part) => part.length > 0)
      .map(SystemPart.make),
    messages: toLLMMessages(input.messages, input.model.ref, providerMetadataKey),
  }
}
```

## Selection carries identity, not state

The two return types are deliberately different shapes.

```ts
// packages/core/src/session/context.ts:29
export interface Selection {
  readonly session: SessionSchema.Info
  readonly agent: Agent.Selection & { readonly info: Agent.Info }
  readonly instructions: Instructions.List
  readonly tools: Tool.Snapshot
}

export interface Loaded {
  readonly session: SessionSchema.Info
  readonly agent: Agent.Selection & { readonly info: Agent.Info }
  readonly model: SessionRunnerModel.Resolved
  readonly initial: string
  readonly messages: ReadonlyArray<SessionMessage.Info>
  readonly tools: Tool.Snapshot
}

/**
 * Resolves model-request state in two phases: `select` fixes the Session,
 * agent, instruction sources, and tool snapshot; `load` adds the model and
 * active history for that selection. Auxiliary operations resolve only the
 * capabilities they need; request preparation stays separate from selection.
 */
```

## Vocabulary from this episode

Full definitions in [`../appendices/D-glossary.md`](../appendices/D-glossary.md).

- **Selection** — the frozen identity of a request: session, agent, instruction sources, and a
  tool snapshot.
- **Loading** — adding the resolved model, the active history, and the frozen baseline.
- **Instruction baseline** — the frozen rendered text of every instruction source at the
  current epoch.
- **Tool guidance** — the conditional lines spliced into the base prompt for the tools present.
- **Prefix cache** — the provider's reuse of a byte-identical prefix as a cache hit.
- **Supersession render** — wording a changed value as a replacement of the old one.

Never call a step a turn.
