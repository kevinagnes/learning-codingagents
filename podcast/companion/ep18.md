## One publish, two audiences

The live channel is documented as volatile by contract, and the volume of a reconnect is the
durable log, not a bigger buffer.

```
// packages/core/src/bus.ts:121
export interface Subscribe {
  /**
   * Volatile live channel: every event published from now on, nothing before or
   * across a disconnect. Consumers that need reliability combine it with `log`.
   * With an ambient Location, delivery is restricted to that Location and global
   * events. Unlocated Session events use the Session's owner at publication time.
   * Session moves reach both the old and new Location, without changing the event.
   */
  (): Stream.Stream<Event.Payload>
  <D extends Event.Definition>(definition: D): Stream.Stream<Event.Payload<D>>
  <const D extends readonly [Event.Definition, ...Event.Definition[]]>(
    definitions: D,
  ): Stream.Stream<SubscribePayload<D>>
}
```

## Facts and hints

The durability kind is declared on the event definition. The stream fragment says so in its
own comment, and names the durable event that carries the final value.

```
// packages/schema/src/session-event.ts:403
  // Stream fragments are live-only; Text.Ended is the replayable full-value boundary.
  export const Delta = Event.ephemeral({
    type: "session.text.delta",
    schema: {
      ...Base,
      assistantMessageID: SessionMessage.ID,
      ordinal: NonNegativeInt,
      delta: Schema.String,
    },
  })
```

The manifest is the same division enforced at the schema layer: internal and replay-only
events never reach the public list, so a client cannot decode them.

```
// packages/schema/src/session-event.ts:704
// Internal and replay-only events are excluded from the public manifest.
export const DurableDefinitions = Event.inventory(
  ...Definitions.filter((definition) => definition.durability === "durable"),
  UsageRecorded,
  MessageContentUpdated,
)
export const EphemeralDefinitions = Event.inventory(
  ...Definitions.filter((definition) => definition.durability === "ephemeral"),
)
```

## Driving the agent

A prompt is admitted durably and then woken. Note that the enqueued item is the return value
of admission, and that the wake is a separate, advisory step.

```
// packages/core/src/session/session.ts:145
const prompt = Effect.fn("Session.prompt")((sessionID: SessionSchema.ID, input: PromptRequest) =>
  Effect.uninterruptibleMask((restore) =>
    Effect.gen(function* () {
      const session = yield* get(sessionID)
      const messageID = input.id ?? SessionMessage.ID.create()
      const admitted = yield* Effect.gen(function* () {
        const existing = yield* admission.reconcile({
          id: messageID,
          sessionID: session.id,
          type: "user",
          delivery: input.delivery ?? "steer",
        })
        if (existing) return existing
        const item = yield* restore(
          SessionPrompt.prepare({ session, messageID, input }).pipe(…),
        )
        // Commit a staged revert only after preparation succeeds, before admitting new work.
        if (session.revert) yield* SessionRevert.commit(bus, session)
        return yield* admission.admit({
          id: messageID,
          sessionID: session.id,
          item,
        })
      }).pipe(…)
      if (input.resume !== false) yield* execution.wake(sessionID)
      return admitted
    }),
  ),
)
```

The other three operations name the same surface: `session.inbox.update` changes a pending
item's delivery, `session.permission.reply` answers a parked request, and `session.interrupt`
stops the active execution with an optional resume.

## Vocabulary from this episode

Full definitions in [`../appendices/D-glossary.md`](../appendices/D-glossary.md).

- **Durable event** — an event with an envelope of aggregate, sequence, and version; the
  replayable boundary.
- **Ephemeral event** — a hint with no envelope, never replayed; the durable end event
  carries the final value.
- **Envelope** — the aggregate identity, sequence number, and schema version on a durable
  event.
- **Projector** — an in-process consumer that folds an event into a read model inside the
  recording transaction.
- **Listener** — a post-commit consumer that feeds the live stream and may miss events.
- **Synced marker** — the point in a log read where replay ends and live delivery begins.
- **Cursor** — the last sequence a client saw, used to read the log after it.
- **Manifest** — the public inventory of event definitions a client may decode.

Never call a hint a record.
