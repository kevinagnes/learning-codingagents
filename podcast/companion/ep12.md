Assembled, that is the text the model reads. Provenance

```text
Spawns an agent in a child session to work on the specified task.
The output includes a sessionID you can pass back later to continue that specific conversation with the subagent.
New child sessions start with fresh context, so include all relevant context and instructions when you don't pass a sessionID.
Foreground (default) runs the subagent to completion and returns its final response.
Background mode (background=true) launches it asynchronously and returns immediately; you are notified when it finishes.
Use background only for independent work that can run while you continue elsewhere.
```

The spoken read says "session identifier" where the source writes a code identifier, reads
the parenthetical default as a comma, and drops the flag from the background sentence. The
prohibitions and the scoping rule are unchanged.

The concrete roster is appended after that text, per request, and only for agents the
calling agent is permitted to run. Each appended line is the agent's identifier and its
description, with a fallback sentence for an agent nobody described: that it should only be
called when explicitly requested.

## The agent record

This is the whole shape: identity, an optional model, request settings, an optional system
override, an optional description, mode, hidden, an optional step limit, and a ruleset. The
default constructor is where the episode's starter policy comes from.

## Selection and the default walk

`selectable` is the single gate. The walk applies it at every step, so a subagent or a
hidden agent is never the default. An explicit id skips the gate entirely, which is how the
subagent tool reaches the subagents the picker will not offer.

```ts
// packages/core/src/agent.ts:74
    const selectable = (agent: Info | undefined) =>
      agent && agent.mode !== "subagent" && !agent.hidden ? agent : undefined
    const selectedDefault = () => {
      const data = state.get()
      const configured = data.default ? selectable(data.agents.get(data.default)) : undefined
      if (configured) return configured
      const build = selectable(data.agents.get(ID.make("build")))
      if (build) return build
      for (const agent of data.agents.values()) {
        const fallback = selectable(agent)
        if (fallback) return fallback
      }
    }

    return Service.of({
      …
      select: Effect.fn("Agent.select")(function* (id) {
        if (id !== undefined) {
          const selected = ID.make(id)
          return { id: selected, info: state.get().agents.get(selected) }
        }
        const info = selectedDefault()
        return { id: info?.id ?? defaultID, info }
      }),
      list: Effect.fn("Agent.list")(function* () {
        const agents = Array.fromIterable(state.get().agents.values())
        const selected = selectedDefault()
        if (!selected) return agents
        return [selected, ...agents.filter((agent) => agent.id !== selected.id)]
      }),
    })
```

## The depth guard

Depth is the length of the parent chain, measured before the child is created. It is a
property of a conversation, so two conversations nest independently.

```ts
// packages/core/src/tool/plugin/subagent.ts:117
              let current = parent
              let depth = 0
              while (current.parentID) {
                depth++
                current = yield* sessions
                  .get(current.parentID)
                  .pipe(
                    Effect.mapError(
                      (error) => new ToolFailure({ message: `Parent session not found: ${current.parentID}`, error }),
                    ),
                  )
              }
              const limit = Config.latest(yield* config.entries(), "experimental")?.subagent_depth ?? 1
              if (depth >= limit)
                return yield* new ToolFailure({
                  message: `Subagent depth limit reached (${limit}). Increase "experimental.subagent_depth" to allow nested subagents.`,
                })
```

## Completion is a durable message

Every terminal state produces the same notice. It is admitted into the parent session as a
synthetic message, and clearing the notification marker is what makes a restart sweep
idempotent.

```ts
// packages/core/src/session/subagent-completion.ts:21
export const deliver = Effect.fnUntraced(function* (
  sessions: Pick<Session.Interface, "synthetic">,
  jobs: Pick<Job.Interface, "completeBackground">,
  input: Pick<Job.Info, "status" | "output" | "error" | "notificationID"> & {
    recovery: Extract<Job.Recovery, { kind: "subagent" }>
    resume?: boolean
  },
) {
  if (input.status === "running") return
  const recovery = input.recovery
  const text =
    input.status === "completed"
      ? (input.output ?? NO_TEXT)
      : input.status === "error"
        ? (input.error ?? "Subagent failed")
        : "Subagent cancelled"
  yield* sessions.synthetic({
    ...(input.notificationID ? { id: input.notificationID } : {}),
    sessionID: recovery.parentSessionID,
    ...(input.resume === false ? { resume: false } : {}),
    description: recovery.description,
    text: `<subagent sessionID="${recovery.childSessionID}" state="${input.status}" description="${recovery.description}">\n${text}\n</subagent>`,
    metadata: { source: "subagent", childID: recovery.childSessionID, agent: recovery.agent, state: input.status },
  })
  if (input.notificationID) yield* jobs.completeBackground(input.notificationID)
})
```

The background return text is the one the episode summarizes as three prohibitions and an
alternative. It names the child's identifier, promises the automatic notification, forbids
sleeping, polling, asking for status, and duplicating the work, and then offers an
alternative: work on non-overlapping tasks, or tell the user what was launched and stop. It
exists because the model sees that string in isolation.

## Vocabulary from this episode

Full definitions in [`../appendices/D-glossary.md`](../appendices/D-glossary.md).

- **Agent** — the named configuration a session runs under.
- **Primary agent** — an agent that may be selected as a session default.
- **Subagent** — a child Session, created by the subagent tool, with its own context.
- **Selectable** — exists, not subagent mode, and not hidden.
- **Depth limit** — the maximum length of the parent chain before spawning is refused.
- **Foreground** — the parent blocks on the child job and receives the final text.
- **Background** — the parent returns immediately and receives a durable notice later.
- **Synthetic message** — a message admitted by the system rather than by a user.

Never call a subagent a function call. It is a session.
