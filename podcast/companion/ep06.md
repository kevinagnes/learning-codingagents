## The artifact, exactly as the model receives it

This is the filled example from Appendix A, § A.36, whose provenance is
`packages/core/src/tool/runtime.ts:88`. The episode reads the four lines with the two field
names spoken as words, and skips the argument block.

```text
Invalid arguments for tool "edit":
- newString: Expected string for form field: newString

Arguments provided:
{
  "path": "a.ts",
  "oldString": "x"
}

Update the arguments and call the tool again.
```

The template that produces it, with each part doing a specific job:

```text
Invalid arguments for tool "${tool}":
- ${path}: ${issue.message}
- ...and ${n} more issues

Arguments provided:
${JSON.stringify(value, null, 2)}

Update the arguments and call the tool again.
```

What each part buys, from the topic's own design commentary:

- The tool name tells the model which call failed when it emitted several.
- The path uses `a.b` and `a[0]` so it matches the JSON the model wrote, and the model can
  repair one field.
- The echoed arguments re-display the exact value, because the model often cannot tell which
  of several similar values was wrong.
- The closing instruction converts an error into a retry. Without it, models explain the
  error to the user instead of fixing it.

## The contract

The whole contract is one small interface. Note the two result channels: `execute` returns a
`Result` whose `output` is machine-checked and whose `content` is what the model reads.

```
// packages/schema/src/tool.ts:92
export type Info<
  Input extends ValueSchema<any> = ValueSchema<any>,
  Output extends ValueSchema<any> | undefined = ValueSchema<any> | undefined,
> = {
  readonly name: string
  readonly input: Input
  readonly description: string
  readonly execute: (input: InputValue<Input>, context: Context) => Effect.Effect<Result<Output>, Error>
  readonly output?: Output
  readonly options?: Options
}
```

## Validation at registration

`add` computes the effective name and refuses a tool that would poison the catalog. Failures
are collected on the editor, logged, and skipped.

```
// packages/core/src/tool.ts:304
function registrationError(tool: Tool.Info) {
  const namespace = tool.options?.namespace
  if (namespace !== undefined) {
    const error = namespaceError(namespace)
    if (error) return error
  }
  const name = normalizedName(tool)
  if (!/^[A-Za-z0-9_-]+$/.test(name)) return new RegistrationError({ name, message: `Invalid tool name: ${name}` })
  const id = effectiveName(tool)
  if (tool.options?.codemode === false && id === "execute")
    return new RegistrationError({ name: id, message: 'Tool name "execute" is reserved for CodeMode' })
  const result = Result.try({
    try: () => ToolDefinition.make(definition(tool)),
    catch: (error) =>
      new RegistrationError({ name: id, message: `Invalid tool definition ${id}: ${schemaMakeError(error)}` }),
  })
  return Result.isFailure(result) ? result.failure : undefined
}
```

## Effective names

Two functions decide the name the model sees. The namespace keeps its dots in the catalog
label and flattens to underscores in the model-facing name.

```
// packages/core/src/tool/runtime.ts:276
export const normalizedName = (tool: Tool.Info) => tool.name.replace(/[^a-zA-Z0-9_-]/g, "_")

export const effectiveName = (tool: Tool.Info) =>
  tool.options?.namespace === undefined
    ? normalizedName(tool)
    : `${tool.options.namespace.replaceAll(".", "_")}_${normalizedName(tool)}`
```

## The captured executor

The snapshot's executor resolves a returned name against the definitions that were advertised,
and keeps two failures distinct: removed for this request, and never existed.

```
// packages/core/src/tool.ts:263
            execute: Effect.fnUntraced(function* (input: Parameters<Snapshot["execute"]>[0]) {
              const context: Tool.Context = {
                sessionID: input.sessionID,
                agent: input.agent,
                messageID: input.messageID,
                id: Tool.CallID.make(input.call.id),

              const event = yield* beforeExecute(input.call.name, input.call.input, context)
              const requested = input.definitions?.get(event.tool)
              // Preserve session context removal and alias resolution, now after the repair hook.
              if (!requested && input.definitions && (direct.has(event.tool) || codeModeTool?.name === event.tool))
                return yield* new Tool.Error({ message: `Tool is not available for this request: ${event.tool}` })
              const name = requested?.name ?? event.tool
              if (name === "execute" && codeModeTool)
                return yield* executeTool(codeModeTool, name, event.input, context)
              const tool = direct.get(name)
              if (tool) return yield* executeTool(tool, name, event.input, context)
              return yield* new Tool.Error({
                message: `No tool named "${name}" is currently available. Please use a tool from the available tool list.`,
              })
            }),
```

## The message builder

```
// packages/core/src/tool/runtime.ts:88
const formatInputIssues = (tool: string, issues: ReadonlyArray<StandardSchemaV1.Issue>, value: unknown) => {
  const details = issues.slice(0, 5).map((issue) => {
    const path =
      issue.path?.reduce<string>((path, segment) => {
        const key = typeof segment === "object" ? segment.key : segment
        if (typeof key === "number") return `${path}[${key}]`
        return path === "" ? String(key) : `${path}.${String(key)}`
      }, "") || "root"
    return `- ${path}: ${issue.message}`
  })
  if (issues.length > 5) details.push(`- ...and ${issues.length - 5} more ${issues.length === 6 ? "issue" : "issues"}`)
  return `Invalid arguments for tool "${tool}":\n${details.join("\n")}\n\nArguments provided:\n${JSON.stringify(value, null, 2)}\n\nUpdate the arguments and call the tool again.`
}
```

Note the cap: `issues.slice(0, 5)`, plus a remainder line. A wall of issues costs the context
the retry needs.

## Vocabulary from this episode

Full definitions in [`../appendices/D-glossary.md`](../appendices/D-glossary.md).

- **Tool** — one object: name, options, description, input shape, optional output shape, and
  an executor that returns a checked output and model-visible content.
- **Options** — namespace, permission action, and the code-mode flags.
- **Registration transform** — the stored edit that a registry replay applies to a fresh
  editor.
- **Effective name** — the flattened name the model sees: namespace dots become underscores.
- **Snapshot** — the definitions and the executor captured together for one request.
- **Decode** — validating the model's arguments against the declared input shape, once, at
  the boundary.
- **Repair** — the conservative pre-pass that fixes only the type errors the shape proves.

Never say "schema" on air. Say "shape".
