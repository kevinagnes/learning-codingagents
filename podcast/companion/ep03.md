## The rule, exactly as the repository writes it

The episode reads this aloud in full. Here is the source line, verbatim.

```
// AGENTS.md:178
- Keep durable events minimal: record irreducible new facts and do not repeat state derivable by folding the ordered aggregate history. Enrich projections and read models with previous or derived state when consumers need self-contained views.
```

## One counter, one unique pair

`seq` is the ordering key. `time_created` exists for range queries and display, never for
order. Two rows cannot share a session and a sequence.

```
// packages/core/src/session/sql.ts:79
export const SessionMessageTable = sqliteTable(
  "session_message",
  {
    id: text().$type<SessionMessage.ID>().primaryKey(),
    session_id: text()
      .$type<SessionSchema.ID>()
      .notNull()
      .references(() => SessionTable.id, { onDelete: "cascade" }),
    type: text().$type<SessionMessage.Type>().notNull(),
    seq: integer().notNull(),
    ...Timestamps,
    data: text({ mode: "json" }).notNull().$type<SessionMessageData>(),
  },
  (table) => [
    uniqueIndex("session_message_session_seq_idx").on(table.session_id, table.seq),
    index("session_message_session_type_seq_idx").on(table.session_id, table.type, table.seq),
    index("session_message_session_time_created_id_idx").on(table.session_id, table.time_created, table.id),
    index("session_message_time_created_idx").on(table.time_created),
  ],
)
```

## The recording transaction

The projectors, the local commit hook, the sequence advance, and the optional raw event row
all run inside one transaction. Subscribers are notified only after the commit.

```
// packages/core/src/bus.ts:395
                        const committed = {
                          ...event,
                          durable: { aggregateID, seq, version: durable.version },
                        } as Event.Payload
                        const route = yield* prepareRoutes([committed])
                        for (const projector of list) {
                          yield* projector(committed)
                        }
                        if (commit) yield* commit(seq)
                        yield* db
                          .insert(EventSequenceTable)
                          .values([{ aggregate_id: aggregateID, seq, owner_id: input?.ownerID }])
                          .onConflictDoUpdate({
                            target: EventSequenceTable.aggregate_id,
                            set: {
                              seq: sql`max(${EventSequenceTable.seq}, ${seq})`,
                              …
                            },
                          })
                          .run()
                          .pipe(Effect.orDie)
                        if (persist)
                          yield* db
                            .insert(EventTable)
                            .values([
                              {
                                id: event.id,
                                aggregate_id: aggregateID,
                                seq,
                                created: event.created ?? 0,
                                type: versionedType(definition.type, durable.version),
                                data: encoded,
                              },
                            ])
                            .run()
                            .pipe(Effect.orDie)
                        return { aggregateID, seq, event: committed, route }
```

## Enrichment inside the projection

The event carries the new model. The projection reads the current model and records it as the
previous value, so the projected message is self-contained.


## The settled prefix

A preview stops at the first assistant entry with no completion time. The runner's own read
does not stop there: the model needs the whole log to continue.

```
// packages/core/src/session/history.ts:146
      Effect.gen(function* () {
        const messages = yield* messageEntries(db, sessionID, boundary)
        // An active assistant may contain an unresolved tool call, so only preview the settled prefix.
        const unsettled = messages.findIndex(
          (entry) => entry.message.type === "assistant" && entry.message.time.completed === undefined,
        )
        const settled = unsettled === -1 ? messages : messages.slice(0, unsettled)
        const assembled = yield* InstructionState.preview(db, sessionID, instructions, observed)
        return {
          initial: assembled.initial,
          messages: settled.map((entry) => entry.message),
          instructionUpdate: assembled.update,
        }
      }),
```

## Vocabulary from this episode

Full definitions in [`../appendices/D-glossary.md`](../appendices/D-glossary.md).

- **Durable** — written down before it is treated as true.
- **Entry** — one typed record in a session's ordered history.
- **Sequence number** — the per-session counter that gives total order without a clock.
- **Event** — a durable fact published to the bus.
- **Projector** — the handler that folds one event type into read models.
- **Read model** — a table shaped for querying, rebuilt from the log.
- **Projection** — folding an event into a read model inside the event's transaction.
- **Aggregate** — the unit a sequence applies to; here, the session.
- **Compaction boundary** — the latest completed compaction a transcript read starts at.
- **Native checkpoint** — a compaction holding the provider's opaque window instead of text.
- **Settled prefix** — the log up to the first assistant entry with no completion time.
- **Replay** — reading the durable log back into the same shaped tables.

Never call a step a turn, and never call a checkpoint a compaction.
